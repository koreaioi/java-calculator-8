# java-calculator-precourse

## 구현 기능 목록

### 1.입력

> - [입력] 사용자로부터 구분자와 양수로 구성된 문자열을 입력받는다.

### 2. 출력

> - [출력] 프로그램 시작 시 `덧셈할 문자열을 입력해 주세요.`를 출력한다.
> - [출력] 프로그램 종료 시 `결과 : %s`를 출력한다.

### 3. 커스텀 구분자 검사

> - [검사] `커스텀 구분자`를 검사한다.
>   - [검사] `커스텀 구분자`가 있는 지 확인한다.
>   - [검사] 문자열 앞부분의 `//`가 0번째 `\n`가 3번째 인덱스에 위치하는 지 확인한다.
>   - [검사] `커스텀 구분자`가 없다면, 사용자가 `커스텀 구분자 입력 형식`을 잘못 작성했는 지 확인한다.
>     - [예외] `\n`를 입력하지 않았을 때,
>     - [예외] `//`를 입력하지 않았을 때,
>     - [예외] 커스텀 구분자가 빈 문자일 때,
>     - [예외] 커스텀 구분자가 `문자열`일 때
>     - [예외] `//`와 `\n`의 순서가 바뀌었을 때
>     - [예외] `커스텀 구분자 입력 형식`이 문자열 중간에 위치할 때
> - [반환] `커스텀 구분자`가 없다면 입력받은 문자열을 그대로 반환한다.

### 4. 커스텀 구분자 추출
> - [추출] `커스텀 구분자`를 추출한다.
>   - [추출] 문자열 `2번째 인덱스` 값을 추출한다. 
>     - [예외] `숫자`는 커스텀 구분자로 사용할 수 없다. (개인 판단)
> - [저장] 추출한 `커스텀 구분자`를 `구분자 저장소`에 저장한다.
> - [반환] 커스텀 구분자 입력 형식`이후의 문자열`을 반환한다.

### 5. 문자열 분리
> - [분리] `구분자 저장소`로부터 모든 구분자를 가져온다.
> - [분리] `구분자를 기준`으로 `분리 패턴`을 만든다.
> - [분리] `문자열`을 `분리 패턴`에 따라 분리한다.
> - [변환] `분리된 문자`들을 `숫자 목록`으로 변환한다.
>   - [요구사항] ""는 0으로 취급한다.
>   - [예외] int 범위의 양의 정수가 아닐 때
>   - [예외] 음수일 때
> - [반환] `변환된 숫자 목록`을 반환한다.

### 6. 숫자 연산
> - [연산] 연산하려는 `숫자`를 전달받는다.
> - [연산] `연산(덧셈)`을 수행한다. 
>   - [예외] 연산 중, int 범위를 넘어갈 때
> - [반환] `연산 결과`를 반환한다.

## 개인 판단
> - [추출] 숫자는 커스텀 구분자로 사용할 수 없다.
>   - [설명] 커스텀 구분자를 숫자로 사용하면, 사용자의 의도를 파악하기 힘들다고 판단했다. 
>   - [설명] //1\n11213인경우 2+3을 해야하는 지, 1+2+3을 해야하는 지 판단하기 어렵다.
> - [빈문자열] `""`는 0으로 취급한다. 
>   - [설명] ,,1,2,3 같은 경우 0+1+2+3으로 처리하기 위해 `""`는 0으로 처리한다.

## 클래스 설명

### [View]

- `ApplicationView`: 어플리케이션에서 수행되는 입출력 비지니스 로직 담당 (안내메세지 후 입력 받기, 결과 출력)
- `InputReader`: 사용자로부터 문자열을 입력 받음
- `OutputReader`: 안내 메세지, 결과를 출력

### [Domain]

- `Number`: 숫자를 표현하는 객체, 숫자로서 연산 및 문자열로부터 변환하는 역할과 책임을 지닌다.
- `Delimiter`: 구분자를 표현하는 객체, 구분자 검증, 구분자 String 반환 역활과 책임을 지닌다.
- `DelimiterStorage`: 기본 구분자와 커스텀 구분자를 관리하는 객체, 구분자 저장, 모든 구분자를 조회하는 역할과 책임을 지닌다.

### [Service]

- `Operator`: 연산 전략을 표현하는 인터페이스, 연산 초기값과 연산 행위를 추상화
- `Adder`: Operator를 상속받은 덧셈 연산 구현체, 덧셈의 초기값으로 0을 제공하고, 두 숫자에 대한 덧셈을 수행하는 역할과 책임을 지닌다.
- `Calculator`: 계산을 수행하는 객체, 피연산자를 받아서 Operator에 정의된 연산을 수행하는 역할과 책임을 지닌다.


- `DelimiterInspector`: 구분자를 검사하는 객체, 커스텀 구분자 입력 형식을 확인하고, 사용자의 잘못된 입력을 검증하는 역할과 책임을 지닌다.
- `DelimiterParser`: 구분자를 파싱하는 객체, 입력된 구분자를 추출하고, 문자열로부터 구분자를 덜어내는 역할과 책임을 지닌다.
- `DelimiterManager`: 구분자를 처리하는 객체, Inspector와 Parser를 통해 구분자 처리 로직을 수행하는 역할과 책임을 지닌다.
- `StringSplitter`: 문자열을 숫자로 분리하는 객체, 구분자 패턴을 생성하고 이를통해 문자열을 숫자로 분리하는 역할과 책임을 지닌다.
- `InputProcessor`: 문자열을 처리하는 객체, 문자열을 전처리(구분자 처리)와 분리를 수행하는 역할과 책임을 지닌다.

### [Controller]
- `CalculatorApplication`: 계산기 애플리케이션의 전체 흐름을 제어하는 객체, 사용자 입력과 결과 출력을 담당하고, 계산 실행을 조율하는 역할과 책임을 지닌다.

### [Common]

- `ErrorMessage`: 예외 상황 메시지를 정의해둔 객체, 오류에 대해 일관된 메시지를 제공하는 역할과 책임을 지닌다.
- `ViewMessage`: 사용자에게 표시할 안내 문구 및 결과 형식을 미리 정의해둔 객체, 일관된 UI 메시지를 제공하고 필요시 결과를 포맷팅하는 역할과 책임을 지닌다


- `DelimiterConstants`: 구분자 관련 상수를 정의해둔 객체
- `NumberConstants`: Number 객체 관련 상수를 정의해둔 객체
- `SplitConstants`: 문자열 분리에 필요한 상수를 정의해둔 객체


- `ViewConfig`: View 계층 객체들의 생성과 관계를 설정하는 객체
- `ProcessorConfig`: Processor 관련 객체들의 생성과 관계를 설정하는 객체
- `CalculatorConfig`: Calculator 관련 객체들의 생성과 관계를 설정하는 객체
- `ApplicationConfig`: 계산기 애플리케이션에 필요한 객체들의 생성과 관계를 설정하는 객체
